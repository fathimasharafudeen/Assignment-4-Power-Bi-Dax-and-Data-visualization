# Assignment 4 – Power BI Dashboard

A Power BI report demonstrating a range of core visualization types, built as part of Assignment 4. The `.pbix` file includes multiple report pages, each showcasing a different chart/visual type, plus a combined dashboard page.

## 📊 Report Pages

| Page | Visuals |
|------|---------|
| New Measure Visualization | Card visuals (custom measures) |
| Clustered Column chart and Donut chart | Clustered column chart, donut chart |
| Line chart and Scatter plot | Line chart, scatter plot |
| Card visuals | Card visuals, action button |
| Map | Map visual |
| Matrix | Pivot table (matrix), action button |
| Funnel | Funnel chart |
| Tree Map | Treemap |
| Dashboard | Combined view — column, donut, line, scatter, card, map, funnel, treemap, and matrix visuals with a summary textbox |

## 🛠️ Tools Used
- **Power BI Desktop** — for report creation and data modeling

## 📁 Files
- `Assignment_4_power_bi.pbix` — the Power BI report file (open with Power BI Desktop)

## 🚀 How to View
1. Download [Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/downloads) (free).
2. Clone or download this repository.
3. Open `Assignment_4_power_bi.pbix` in Power BI Desktop.
4. Navigate between report pages using the page tabs at the bottom.

> **Note:** GitHub does not render `.pbix` files in the browser — you'll need Power BI Desktop (Windows only) to view and interact with the report.
